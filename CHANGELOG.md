# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/2.0.0/),
and this project uses [Semantic Versioning](https://semver.org/) with a
`-preview` prerelease suffix until the MVP is feature-complete (see
[docs/runbook.md](docs/runbook.md#versioning--releases) for the scheme).
From `0.1.0-preview` onward, entries are generated by
[release-please](https://github.com/googleapis/release-please) from
Conventional Commit-formatted PR titles; this initial entry was written by
hand as a one-time bootstrap.

## [0.1.0-preview] - 2026-09-18

Initial public prerelease.

### Added

- Mode selection screen with single-user, collaborative-host, and
  collaborative-join entry points.
- Single-user (Mode B) estimation flow: session setup, estimate entry with
  uncertainty-range guard, summary, and history.
- Live collaborative sessions over a Trystero-based peer-to-peer network:
  join by code, participant estimating/waiting/revealed flow, facilitator
  reveal and round control, synced session unit and display names.
- Production deployment to IONOS Deploy Now with GitHub Actions CI
  (lint, format, typecheck, test, build) gating every PR.
- In-app feedback link and error boundary for the deployed preview build.
